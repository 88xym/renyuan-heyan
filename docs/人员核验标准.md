# 人员入场资料核验标准

> 版本：v2.0 ｜ 更新日期：2026-09-07
> 适用范围：总包中国港湾工程有限责任公司入场人员资料审核
> 配套程序配置：`config/verification_rules.yaml`（程序可读版本）

---

## 核验总原则

1. **手写的位置不重要，主要看打印内容**；手写体做宽松识别
2. **所有"与证件复印件一致"的检查**，以本 PDF 内证件扫描页为基准
3. 照片/图片"清晰可认"为人工核验项

### 宽松识别规则（详见 `config/check_policy.yaml`）

| 情形 | 处理 |
|---|---|
| 手写签名看不清 | ✅ 视为已签署 |
| 数字 0 与字母 O 混淆 | ✅ 视为一致 |
| 手写日期格式异常（如 `20267-18`） | ✅ 降级为"建议核对" |
| 字段完全空白（无任何书写痕迹） | ❌ 判为缺失 |

---

## 一、三类人员资料清单

### 1. 澳门本地人（持澳门身份证）

| # | 资料 | 必附 | 说明 |
|---|---|---|---|
| 1 | 申请人个人资料页 | ✅ | 信息与证件扫描件一致，中间框附照片：**澳门身份证** + **建筑业职安卡**，清晰可认 |
| 2 | 申请人声明 | ✅ | 姓名、单位、证件号码正确，签名+签日期（宽松） |
| 3 | 承判商声明 | ✅ | 一包单位名称；负责人签字+盖章；合同逻辑见下文 |
| 4 | 合同页 | 条件性 | 直属总包免附；二判/三判必附（见合同逻辑） |
| 5 | 证件复印件页 | ✅ | 附澳门身份证、职安卡，与第一页一致 |
| 6 | **身份证真伪记录** | ✅ | **澳门身份证人员必须提供**，其余证件无须提供 |

### 2. 特别逗留证人士

| # | 资料 | 必附 | 说明 |
|---|---|---|---|
| 1 | 申请人个人资料页 | ✅ | 中间框附照片：**特别逗留证** + **建筑业职安卡**，清晰可认 |
| 2 | 申请人声明 | ✅ | 同左 |
| 3 | 承判商声明 | ✅ | 同左 |
| 4 | 合同页 | 条件性 | 直属总包免附；二判/三判必附 |
| 5 | 证件复印件页（1-2张） | ✅ | 附**往来港澳通行证、职安卡、特别逗留证**，与第一页一致 |

> 特别逗留证人员**无**身份证真伪记录要求。

### 3. 外地雇员身份识别证（蓝卡）

| # | 资料 | 必附 | 说明 |
|---|---|---|---|
| 1 | 申请人个人资料页 | ✅ | 中间框附照片：**蓝卡** + **建筑业职安卡**，清晰可认 |
| 2 | 申请人声明 | ✅ | 同左 |
| 3 | 承判商声明 | ✅ | 同左 |
| 4 | 合同页 | 条件性 | 直属总包免附；二判/三判必附 |
| 5 | 证件复印件页 | ✅ | 附**往来港澳通行证、职安卡、蓝卡**（或行街纸+红印纸） |
| 6 | 劳工三表 | ✅ | 劳工事务局申请信函、劳工局批示、治安警察局逗留许可申请表，**三表内容须互相对应** |

**蓝卡特殊情况（未颁发时）：**

> 蓝卡尚未颁发时，治安警察局会发一张收据（俗称**行街纸**）和一张带二维码的纸条（俗称**红印纸**）。行街纸 + 红印纸具有同等法律意义，此时**身份证副本位置可空缺**。

**劳工三表对应关系：** 三份表格中的姓名、证件号码、公司、日期需互相对应，证明该人员合法。

## 二、申请人个人资料页检查项

| 检查项 | 要求 |
|---|---|
| 中文姓名 | 与证件扫描件一致 |
| 英文姓名 | 与证件扫描件一致 |
| 日期 | 与证件扫描件一致 |
| 承判公司 | 与证件扫描件/申报一致 |
| 承判工程项目 | 填写准确 |
| 职安卡资料 | 编号、有效期与证件复印件一致 |
| 照片 | 中间框附对应证件+职安卡，清晰可认（人工项） |

---

## 三、申请人声明检查项

| 字段 | 必填 | 检查方式 |
|---|---|---|
| 姓名 | ✅ | 填写正确 |
| 单位 | ✅ | 填写正确 |
| 证件号码 | ✅ | 填写正确 |
| 签名 | ✅ | **宽松识别——只要签名即可**，看不清视为已签署 |
| 签署日期 | ✅ | **宽松识别**——格式异常不直接判错，完全空白判缺失 |

---

## 四、承判商声明检查项（三类人员共用）

**结构要求：**
- 第一大项：**一包单位名称**
- 第二大项：甲乙丙用于区分**二判、三判、四判**等
- 承判商负责人**签字 + 盖章**

**合同页供给逻辑（关键判断）：**

```
承判商声明中填写的单位 vs 第一页承判公司名称
        │
        ├─ 不一致 → 该单位是第一页承判公司的二判或三判
        │           → 需补充：
        │              ① 二判与三判之间合同
        │              ② 二判与一判之间合同
        │
        └─ 无其他单位 → 与总包（中国港湾）是直属承判关系
                        → 无需提供合同
```

---

## 五、证件页检查项

- 该页附上人员证件，**与第一页（个人资料页）证件应当一致**
- 各人员类型的证件清单：

| 人员类型 | 证件页应包含 |
|---|---|
| 澳门本地人 | 澳门身份证、建筑业职安卡 |
| 特别逗留证 | 往来港澳通行证、职安卡、特别逗留证 |
| 蓝卡 | 往来港澳通行证、职安卡、蓝卡（或行街纸+红印纸） |

---

## 六、身份证真伪记录

- **仅澳门身份证人员须提供**身份证真伪记录
- 其余证件（特别逗留证、蓝卡）无须提供
